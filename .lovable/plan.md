# แก้ Google reCAPTCHA ที่วนซ้ำ

## สิ่งที่จะทำ
- ป้องกัน widget ถูกสร้างหรือตรวจ token ซ้ำเมื่อหน้าฟอร์มวาดใหม่
- เก็บสถานะ “ผ่านแล้ว” ให้คงอยู่จนกดเข้าสู่ระบบหรือสมัครสมาชิก
- แสดงสาเหตุที่ตรวจไม่ผ่านให้ชัดเจน แทนข้อความผิดพลาดรวม ๆ
- รองรับการโหลดสคริปต์ Google ซ้ำและการหมดอายุของ token อย่างปลอดภัย

## การตรวจสอบ
- ตรวจว่าหน้าเข้าสู่ระบบและสมัครสมาชิกมี widget จุดละหนึ่งตัว
- ตรวจคำขอตรวจ token และสถานะหลัง Google ส่งผลสำเร็จ
- ตรวจหน้าเว็บบนมือถือและผลการสร้างเว็บ

## รายละเอียดทางเทคนิค
- ทำ callback และ server-function references ให้คงที่ เพื่อไม่ให้ React effect ยกเลิก callback ระหว่างตรวจ
- ล็อกคำขอตรวจ token ต่อหนึ่งครั้ง และไม่ reset widget หลังผ่าน
- ส่ง error code ที่ปลอดภัยจาก Google มาแปลเป็นข้อความสำหรับผู้ใช้
